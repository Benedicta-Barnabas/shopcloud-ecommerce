## Background
E-commerce is one of the fastest growing industries globally. 
Businesses of all sizes need reliable, scalable platforms to 
sell their products online. This project solves the problem of 
building and deploying a production-ready e-commerce platform 
on the cloud, making it accessible, scalable and highly available.

## Understanding
My approach was to build a three-tier cloud architecture:
- **Frontend** (React) — what the customer sees
- **Backend** (Node.js + Express) — handles business logic
- **Database** (MongoDB) — stores products, users and orders

Each tier is deployed on its own AWS EC2 instance, mirroring 
real world production environments used by companies today.
